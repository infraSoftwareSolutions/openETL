### LIBRARY OVERVIEW

This header defines comprehensive exception classes for the lite library. 
The hierarchy of exceptions includes:
- LITE___exception (base class): Provides a consistent interface for 
handling with support for custom error messages and proper exception 
hierarchy.
- internal_exception: Internal library errors.
- OutOfRange: Index or value out of valid range.
- undefined_behavior: Undefined behavior detected.
- wrong_indexing: Invalid indexing operations.
- wrong_declaration: Incorrect declarations.
- wrong_construction: Invalid object construction.
- wrong_input: Invalid input data or parameters.

### OBJECTS & DATA STRUCTURES

#### Object: exception
------------------

Description: The base class for all lite library exceptions. It provides 
consistent interface for error handling with support for custom error 
messages and proper exception hierarchy.

Members:
  - message (type ocf::str): Stores the error message describing the 
exception.
  
#### Object: internal_exception
----------------------------

Description: Exception for internal library errors. Thrown when an 
internal error occurs within the lite library that indicates a logic 
or implementation issue.

Members:
  - None
  
#### Object: OutOfRange
----------------------

Description: Exception for out-of-range access attempts. Stores index and 
size information for context.

Members:
  - index_ (type size_t): The out-of-range index.
  - valid_size_ (type size_t): The maximum valid size.

#### Object: undefined_behavior
----------------------------

Description: Exception for undefined behavior detection. Thrown when 
undefined behavior is detected during execution, such as null pointer 
dereferences or invalid state transitions.

Members:
  - None
  
#### Object: wrong_indexing
-------------------------

Description: Exception for invalid indexing operations. Thrown when an 
indexing operation is invalid, such as using negative indices where only 
positive indices are expected, or accessing uninitialized indices.

Members:
  - invalid_index_ (type int): The problematic index value.

#### Object: wrong_declaration
----------------------------

Description: Exception for incorrect variable or type declarations. 
when a variable, function, or type declaration is incorrect or when there 
is a type mismatch in declarations.

Members:
  - None
  
#### Object: wrong_construction
-----------------------------

Description: Exception for invalid object construction. Thrown when an 
object cannot be constructed properly due to invalid parameters or 
preconditions not being met.

Members:
  - None
  
#### Object: wrong_input
----------------------

Description: Exception for invalid input data or parameters. Thrown when 
input data or parameters do not meet the expected requirements, 
constraints, or format specifications.

Members:
  - input_value_ (type ocf::str): The problematic input value.

### FUNCTIONS

#### Function: internal_exception(const ocf::str& message = "")
----------------------------------------------------

Purpose: Constructs an instance of `internal_exception` with a custom 
error message. If no message is provided, it defaults to "Internal 
error".

Parameters:
  - message (type ocf::str): The optional error message for the exception.

Returns: None

Notes: 

#### Function: ~internal_exception()
----------------------------------

Purpose: Virtual destructor for `internal_exception`. Ensures proper 
cleanup in derived classes.

Parameters: None

Returns: None

Notes:

#### Function: what() const noexcept override
--------------------------------------------------

Purpose: Returns a pointer to the error message as a C-string. If the 
message is empty, it returns "lite exception".

Parameters: None

Returns:
  - Pointer to the error message C-string

Notes: Override of the standard `what` method for custom exceptions.

#### Function: get_message() const noexcept
------------------------------------------

Purpose: Returns a reference to the error message string. Allows 
the stored error message without modifying it.

Parameters: None

Returns:
  - Reference to the error message string

Notes:

#### Function: OutOfRange(const ocf::str& message = "Out of range", 
index = 0, size_t valid_size = 0)
---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

Purpose: Constructs an instance of `OutOfRange` with a custom error 
message and out-of-range index. If no message or index is provided, it 
defaults to "Out of range".

Parameters:
  - message (type ocf::str): The optional error message for the exception.
  - index (type size_t): The problematic index value. Defaults to 0.
  - valid_size (type size_t): The maximum valid size. Defaults to 0.

Returns: None

Notes:
