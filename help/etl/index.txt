### LIBRARY OVERVIEW

This library contains a class named `index` which is designed to 
an index with an explicit validity state. The primary purpose of this 
library is to provide a robust and safe way to handle indices, ensuring 
they remain valid before use, thus avoiding the pitfalls associated with 
uninitialized or invalid values.

### OBJECTS & DATA STRUCTURES

#### Object: index
**Description:** This object represents a size-based index that can be 
marked as valid or invalid. It also provides methods for setting the 
index's value and checking its validity in various contexts.

##### Members:

- **ind (size_t):** Stores the numeric value of the index.
- **is_valid (bool):** Indicates whether the index is currently usable.
