### LIBRARY OVERVIEW

This library/file contains a collection of various functions and 
related to strings, vectors, matrices, mathematical operations, and 
manipulations. It is designed for use in C++ applications where these 
functionalities are required.

### OBJECTS & DATA STRUCTURES

#### ocf::str (Object)
- **Description:** Represents a sequence of characters, similar to a 
string.
- **Members:**
  - `std::vector<char>` content: Stores the actual character data in the 
object.

#### ocf::vec<T> (Object)
- **Description:** A templated vector that can hold elements of any type 
T.
- **Members:**
  - `std::vector<T>` container: Holds the elements as a vector for 
memory management and indexing.
