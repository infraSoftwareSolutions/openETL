### LIBRARY OVERVIEW

A header file defining the Ternary class for representing ternary logic 
values. The Ternary class provides methods for setting, getting, and 
manipulating ternary logic values, which can be true, false, or unknown. 
The class includes constructors, assignment operators, logical operators, 
and comparison operators to facilitate the use of ternary logic in C++ 
programs.

### OBJECTS & DATA STRUCTURES

**Object: Ternary**
------------------

- value (enum): Internal representation of the ternary logic value: 
TRUE, or UNKNOWN
