### LIBRARY OVERVIEW

A collection of functions for generating random numbers, characters, and 
vectors, as well as performing simple shift encryption on strings. These 
functions utilize the Mersenne Twister algorithm for random number 
generation and provide both simple and complex encryption methods.

The library is designed to be `noexcept`, ensuring they do not throw 
exceptions. This design allows for better performance in exception-safe 
code. The functions are organized into categories such as random number 
generation (`GRN`), character generation (`GRC`), vector generation 
(`GRV`), encryption (`SES` and `SEC`), and various vector and character 
generation methods.

#### Function: GRN(start, end)
----------------------

**Purpose:** Generates a random integer within the specified range using 
Mersenne Twister algorithm.
  
**Parameters:**
  - start (int): The lower bound of the range (inclusive).
  - end (int): The upper bound of the range (inclusive).

**Returns:** A random integer between start and end (inclusive)

**Notes:** Uses a static random generator initialized once per program 
execution. Does not throw exceptions.

**Parameters:** None

(32 to 126)

**Notes:** Converts an integer generated by GRN() into a char. Does not
