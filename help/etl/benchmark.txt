# LIBRARY OVERVIEW

A lightweight code execution timer and memory usage measurement utility.

This library provides a lightweight `code_timer` class for 
measuring the duration of function executions in two modes: 
RAII (in-structure = true) or manual (in-structure = false).

It includes overloaded functions to measure the execution time of various types of callables,
such as parameter less functions,
single-argument functions,
and two-argument functions with different types.

Additionally, it offers functions for simulating various time
complexities and estimating the time complexity of an algorithm
based on measured execution time.

## OBJECTS & DATA STRUCTURES

### code_timer

#### Description
A class for timing code execution,
supporting both RAII (in-structure = true)
and manual modes (in-structure = false).

#### Members:
  - started (bool):
    Indicates whether the timer is running.
  - start (std::chrono::time_point<std::chrono::high_resolution_clock>):
    Time when timing starts.
  - end (std::chrono::time_point<std::chrono::high_resolution_clock>):
    Time when timing ends.
  - mycodetime (std::chrono::duration<float>):
    Duration of the code execution measured in seconds.

### big_O1, logn, big_On, logn_n, big_On2, big_On3

#### Description
Functions to simulate different time complexities
for benchmarking purposes.

## FUNCTIONS

### execution_time<T>(ocf::func<T()> input_func)

#### Purpose
Measures the execution time of a parameter less function.
It takes a callable object as an argument and executes 
it once using @ref code_timer in manual mode.

#### Parameters:
- input_func (ocf::func<T()>):
  The function or lambda to measure its execution time.

#### Returns: 
- Execution time in seconds as a floating-point value, 
  multiplied by 1000.0f if milliseconds are desired.

#### Example Usage:
```cpp
auto duration = etl::benchmark::execution_time<void>([] {
    heavy_computation();
});
std::cout << "Duration: " << duration * 1000.0f << " ms\n";
```

### execution_time<T, T2>(ocf::func<T(T2)> input_func, T2 arg)

#### Purpose
Measures the execution time of a single-argument function.

#### Parameters:
- input_func (ocf::func<T(T2)>): 
  The function to measure its execution time.
- arg (T2):
  Argument to pass to the function.

### execution_time<T1, T2, T3>(ocf::func<T1(T2, T3)> input_func, T2 arg1, T3 arg2)

#### Purpose
Measures the execution time of a two-argument function with different types.

#### Parameters:
- input_func (ocf::func<T1(T2, T3)>): The function to measure its execution time.
- arg1 (T2): First argument to pass to the function.
- arg2 (T3): Second argument to pass to the function.

### execution_type(float time, int num, int logbase = 10)

#### Purpose
Estimates the time complexity of an algorithm based on measured execution time.
It compares the provided execution time against predefined time benchmarks for standard complexities:
  O(1), 
  O(log n), 
  O(n), 
  O(n log n), 
  O(n^2), 
  and higher exponential or factorial complexities.

#### Parameters:
- time (float): Measured execution time in seconds.
- num (int): Input size used in the benchmark functions.

#### Example Usage:
```cpp
ocf::str complexity = etl::benchmark::execution_type(0.0023, 1000);
std::cout << "Estimated complexity: " << complexity << "\n";
```

### function_data<T>(ocf::func<T()> f)

#### Purpose
  Measures additional memory usage caused by 
  executing a parameter less function.

#### Parameters:
- f (ocf::func<T()>):
  The function to execute and measure its memory usage for,
  e.g., vector or string operations.

#### Returns: 
- Additional memory used in bytes (0 if no increase).

### function_data<T1, T2>(ocf::func<T1(T2)> f, T2 input)

#### Purpose
Measures additional memory usage caused by executing 
a single-argument function.

#### Parameters:
- f (ocf::func<T1(T2)>): 
  The function to execute and measure its memory usage for.
- input (T2): Argument to pass to the function.

### function__data<T1, T2, T3>(ocf::func<T1(T2, T3)> f, T2 arg1, T3 arg2)

#### Purpose
  Measures additional memory usage caused 
  by executing a two-argument function.

#### Parameters:
- f (ocf::func<T1(T2, T3)>): 
  The function to execute and measure its memory usage for.
- arg1 (T2): 
  First argument to pass to the function.
- arg2 (T3): 
  Second argument to pass to the function.

### stream<print_result> (TFactor = "ms")

#### Purpose
  A template class for benchmarking function execution time.
  Allows users to measure and record the execution 
  time of functions, with optional results printing 
  based on a specified time unit.

## NOTES

- This library is designed for benchmarking code 
  performance in C++23.
- The `code_timer` class can be used in 
  both RAII and manual modes depending on 
  the value of the `in_structure` 
  template parameter.
- Functions like `execution_time`, 
  `execution_type`, etc., provide 
  a flexible way to measure different 
  aspects of function execution and time 
  complexity estimation.
