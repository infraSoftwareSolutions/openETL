## LIBRARY OVERVIEW

This library provides various sorting algorithms for both strings and 
vectors. The sorting algorithms include Bubble Sort, Selection Sort, Comb 
Sort, Heap Sort, Insertion Sort, Merge Sort, and Quick Sort. Each 
takes the appropriate data type as input (either a string or a vector) 
returns the sorted form of the input data.

## OBJECTS & DATA STRUCTURES

### Object: etl::is_sorted(const std::string& value, bool increasing)
------------------
- **Value**: A const reference to a `std::string` representing an array 
characters.
- **Increasing**: A boolean indicating whether the sort should be in 
ascending (true) or descending (false) order.

### Function: is_sorted(const std::string& value, bool increasing)
--------------------------------------------------------
**Purpose**: Checks if the given string is sorted based on the specified 
order (ascending or descending).

**Parameters**:
- **value** (std::string): The string to be checked.
- **increasing** (bool): Whether the sort should be in ascending order.

**Returns**: True if the string is sorted according to the specified 
order, otherwise false.

### Function: is_sorted(const std::vector<T>& value, bool increasing)
--------------------------------------------------------
**Purpose**: Checks if the given vector is sorted based on the specified 
order (ascending or descending).

**Parameters**:
- **value** (std::vector<T>): The vector of elements to be checked.
- **increasing** (bool): Whether the sort should be in ascending order.

**Returns**: True if the vector is sorted according to the specified 
order, otherwise false.
