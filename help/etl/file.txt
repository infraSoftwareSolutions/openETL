### LIBRARY OVERVIEW
================

A simple text file manager class for creating, reading, appending, 
checking existence, and removing text files in a specified directory. 
library provides the `txtfile_manager` class to easily manage text files 
without dealing with low-level file handling operations.

It ensures that the specified directory exists and provides methods for 
common file operations such as creating, reading, appending, checking 
existence, and removing files in a specified directory. The library is 
designed to be convenient for handling text files in C++ projects.

### OBJECTS & DATA STRUCTURES
=========================

#### Object: `file`
------------------

**Description:** This object encapsulates functionalities to manage text 
files, including creating, reading, appending, checking existence, and 
removing text files in a specified directory.

**Members:**

- **directory (std::filesystem::path):** The path of the managed 
where text files will be created, read, appended, checked for existence, 
or removed.
  
### FUNCTIONS
=========

#### Function: `file()`
---------------------------------

**Purpose:** Constructs a `txtfile_manager` object that manages text 
in the current working directory.

**Parameters:** None

**Returns:** N/A

**Notes:** This constructor uses the current working directory as the 
default managed directory. If you want to manage text files in a 
directory, create an instance of `file` with the desired path using the 
second parameter (`const ocf::str &dirPath`).

#### Function: `change_directory(const ocf::str &dirPath)`
---------------------------------------------------------

**Purpose:** Changes the directory where text files are managed. If the 
new directory does not exist, it will be created.

**Parameters:**
- **dirPath (std::string):** The path to the directory where text files 
will be managed.

**Returns:** N/A

**Notes:** This method is useful when you need to manage text files in a 
different location within your project. It ensures that the directory 
exists before managing any files within it.

#### Function: `make_directory(const ocf::str &dirPath)`
------------------------------------------------------

**Purpose:** Creates a new directory if it does not already exist.

**Parameters:**
- **dirPath (std::string):** The path of the directory to create.

**Returns:** N/A

**Notes:** This method is useful for ensuring that directories used by 
`txtfile_manager` have been created. If you need to manage text files in 
new or existing directory, this method helps ensure those directories are 
available before creating any files within them.

#### Function: `create(const ocf::str &filename)`
----------------------------------------------------

**Purpose:** Creates a new text file with the specified filename in the 
managed directory. The file will be overwritten if it already exists.

**Parameters:**
- **filename (std::string):** The name of the file to create.

**Returns:** N/A

**Notes:** If the file cannot be created due to permissions issues or 
other reasons, a `std::runtime_error` is thrown with an appropriate error 
message. It's important to handle these errors appropriately in your code.

#### Function: `append(const ocf::str &filename, const ocf::str &content)`
--------------------------------------------------------------------------

**Purpose:** Appends content to an existing text file. If the file does 
not exist, it will be created.

**Parameters:**
- **filename (std::string):** The name of the file to append to.
- **content (std::string):** The content to append.

**Returns:** N/A

**Notes:** If the file cannot be opened for appending due to permissions 
issues or other reasons, a `std::runtime_error` is thrown with an 
appropriate error message. It's important to handle these errors 
appropriately in your code.

#### Function: `read(const ocf::str &filename)`
---------------------------------------------------

**Purpose:** Reads the contents of a text file and returns it as a string.

**Parameters:**
- **filename (std::string):** The name of the file to read.

**Returns:** A `std::string` containing the contents of the specified 
file. If the file does not exist, this method will throw a 
`std::runtime_error`.

**Notes:** If the file cannot be opened for reading due to permissions 
issues or other reasons, a `std::runtime_error` is thrown with an 
appropriate error message.

#### Function: `exists(const ocf::str &filename)`
---------------------------------------------------

**Purpose:** Checks if the specified text file exists in the managed 
directory.

**Parameters:**
- **filename (std::string):** The name of the file to check for existence.

**Returns:** A boolean indicating whether the specified file exists. 
Returns true if the file exists, false otherwise.

#### Function: `remove(const ocf::str &filename)`
---------------------------------------------------

**Purpose:** Removes a text file from the managed directory.

**Parameters:**
- **filename (std::string):** The name of the file to remove.

**Returns:** N/A

**Notes:** If the specified file does not exist, this method will throw a 
`std::runtime_error` with an appropriate error message. It's important to 
handle these errors appropriately in your code.
