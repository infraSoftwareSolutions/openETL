### LIBRARY OVERVIEW

This header file defines several utility classes and functions for 
managing vectors in C++. The library provides a flexible stream-like 
interface (`vstream`) to manage a vector of type `T`, including 
extraction, and various utility functions. Additionally, it includes 
benchmarking functionality with the `benchmark_stream` class and 
aggregation capability with boolean test results using exception handling 
through the `test_stream` class.

### OBJECTS & DATA STRUCTURES

#### Object: vstream
------------------

**Description:** 
A vector-like interface for managing a vector of type `T`. It supports 
insertion, extraction, and utility functions to manage the underlying 
vector. The `vstream` class is designed as a stream interface that allows 
easy manipulation and management of vectors.

**Members:**
- `vs`: A queue of vectors (`ocf::que<ocf::vec<T>>`) representing the 
internal container for managing elements.
  - **size()**: Returns the current number of elements in the vector (no 
exceptions).
  - **empty()**: Checks if the vector is empty (no exceptions).
  - **clear()**: Removes all elements from the vector (no exceptions).

#### Object: sstream
-----------------

**Description:** 
A stream-like interface for managing strings (`ocf::str`) and supporting 
split functionality. The `sstream` class allows users to insert values, 
extract values, and manage internal splitting.

**Members:**
- `split`: A boolean flag indicating whether the string should be split.
- `split_str`: A string used for splitting if `split` is true.
- `ss`: An internal queue of strings (`ocf::que<ocf::str>`) representing 
the stream elements.

#### Object: sstream
-----------------

**Description:** 
A stream-like interface for managing a single string and supporting split 
functionality. The `sstream` class allows users to insert values, extract 
values, and manage internal splitting directly from the constructor or by 
setting specific flags.

- **set_split(bool isSplit)**: Sets whether the string should be split.
- **set_split_str(const ocf::str &ssplit)**: Sets a custom string used 
splitting if `split` is true.
- **operator<<(const ocf::str &value)**: Inserts a value into the stream. 
If split, it handles splitting and insertion of substrings.
