## Library Overview: CodeLineCounter Module - Count Lines of Code in 
PowerShell Files and Directories

The `CodeLineCounter` module provides functionality to count the number 
lines within various types of files, with a focus on source code. It can 
handle both individual files and entire directories containing multiple 
language-specific files. The main purpose of this library is to automate 
the process of calculating line counts for quality assurance purposes or 
estimating effort in development work.

## Objects & Data Structures: `PSCustomObject`
------------------------------
This custom object, represented as `[pscustomobject]`, serves as a 
container that holds information about each file being processed 
its name, path, line count, and type (File or Folder). It's used to 
aggregate results throughout the counting process.
```powershell
$result += [PSCustomObject]@{
    Name = $file.Name
    Path = $file.FullName
    Lines = $lineCount
    Type = 'File'
}
```
