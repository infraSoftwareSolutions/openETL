# LIBRARY OVERVIEW
This PowerShell module `autoDoc.psm1` provides functionality to generate 
documentation for source code files using the language modeling 
capabilities of Ollama. The main purpose of this library is to facilitate 
automated, consistent comment generation within various programming 
languages by leveraging a pre-trained AI like Codex (formerly known as 
Phi). It supports generating different types of documentation outputs 
as plain text (`txt`), Markdown (`md`), and Doxygen-style comments.

## Set-OllamaModel(parameters)
**Purpose:** Change the Ollama model name that will be used by 
`Invoke-AutoDoc`. This function allows specifying a different AI 
language/model if desired, which can affect documentation generation for 
various programming languages.

**Parameters:**
- $Name (string): Name of the new or existing Ollama model to set as 
default. The name should correspond with an available Codex variant like 
"phi3:mini". This is mandatory and has a global setting that defaults to 
this value if not otherwise specified.

Returns nothing directly, but internally updates `$script:OllamaModel`.

Notes/Important considerations: 
- The Ollama model name can be changed dynamically before invoking 
`Invoke-AutoDoc`, influencing how different code snippets will be 
documented based on the language's syntax and commenting conventions.

Code snippet example (requires removal of unnecessary markdown fence 
characters):
```powershell
function Set-OllamaModel {
    param(
        [Parameter(Mandatory=$true)]
        [string]$Name
    )
    $script:OllamaModel = $Name
    Write-Host "Ollama model set to: $script:OllamaModel" 
Green
}
```

## Invoke-OllamaPrompt(parameters)
**Purpose:** Send prompts to Ollama and receive responses, then format 
these as strings if needed before further processing or outputting.
Returns nothing directly but provides a mechanism for handling the AI's 
raw text response from `Invoke-AutoDoc`.
```powershell
function Invoke-OllamaPrompt {
    param([string]$Prompt)
    $output = $Prompt | ollama run $script:OllamaModel
    if ($LASTEXITCODE -ne 0) {
        throw "ollama exited with code $LASTEXITCODE"
    }
    return ($output -join [Environment]::NewLine)
}
```
